## สิ่งที่ทดสอบแล้วทำงาน

- หน้าโหลดเริ่มต้นเข้า MainMenu สำเร็จ โหลด metadata การ์ด 4 รายการ และไม่มีรูปค้างอยู่ใน pending_requests ณ จุดตรวจ
- สร้างห้องและ Guest เข้าห้องผ่าน API ของเกมได้จริง ทั้งสอง WebSocket เชื่อมต่อได้
- ตำแหน่งการ์ดบนสนามและการเอียงการ์ดส่งถึง Guest: ตำแหน่ง (500,300), มุม 90°
- ย้ายการ์ดจากสนามขึ้นมือ Host แล้วการ์ดบนสนาม Guest ถูกนำออก และมือ Host มีการ์ดเพิ่ม
- Local สองผู้เล่น: จั่วแล้วสลับผู้เล่น มือผู้เล่นอีกคนว่าง และสลับกลับได้การ์ดเดิม
- Deck Editor บันทึกและโหลดไฟล์รูปแบบใหม่เองได้: 1 กลุ่ม 3 copies
- Field Creator บันทึกและโหลดองค์ประกอบ 4 ชิ้น รวม parent ของการ์ดใน sub-field และค่าเริ่มต้น counter 10 ได้

## ข้อจำกัดเพิ่มเติมจากการอ่านโค้ด

- Card Selector และคลังการ์ดใน Deck Editor โหลดรายการจาก Supabase เป็นหลัก ยังไม่พบเส้นทาง UI เปิดการ์ด local ใน Card Selector จึงยังไม่เป็น workflow local ที่ครบถ้วน
- HTTPRequest ใน SupabaseService ไม่ตั้ง timeout ของแอป และหน้าเริ่มต้นรอโหลด metadata/รูปทั้งหมด ยังไม่ได้จำลองเซิร์ฟเวอร์ค้างหรืออินเทอร์เน็ตที่ช้ามาก จึงเป็นความเสี่ยงที่ต้องทดสอบเพิ่ม ไม่ใช่อาการค้างที่ยืนยันในรอบนี้
- ยังไม่ได้ทดสอบการ์ดจำนวนมาก ผู้เล่นมากกว่าสองคน อินเทอร์เน็ตต่างเครือข่าย การหลุดแบบ packet loss จริง หรือไฟล์เกมที่ export แล้ว
- การเข้า online รอบแรกส่ง player_joined/request_field_state ทันทีเมื่อ WebSocket เปิดก่อนตรวจคำตอบ phx_join เป็นความเสี่ยงเรื่องลำดับเหตุการณ์ แต่การเข้าห้องรอบที่ทดสอบสำเร็จ

## สถานะการล้างข้อมูลทดสอบ — ยังไม่สมบูรณ์

ทั้ง Host และ Guest หยุดแล้ว ห้องทดสอบอยู่สถานะ `closed` แต่ยังมีแถวค้างอยู่:

- DELETE ด้วยเงื่อนไข **ทั้ง id และ name ของห้องทดสอบ** ตอบ HTTP 200 แต่คืนรายการที่ลบได้ 0 แถว
- GET ยืนยันหลังลบตอบ HTTP 200 และยังพบ 1 แถว
- ลักษณะนี้สอดคล้องกับข้อจำกัดสิทธิ์/RLS แต่ยังไม่ได้อ่าน policy จึงไม่ยืนยันสาเหตุ
- Computer Use พบหน้า Supabase ที่เปิดอยู่ แต่หยุดก่อนดำเนินการเพราะไม่สามารถยืนยัน URL บน Windows ได้ จึงไม่ได้ลบผ่าน Dashboard

เตรียม [SQL สำหรับลบเฉพาะห้องทดสอบ](QA_CLEANUP_2026-10-02.sql) ให้รันด้วยสิทธิ์ Dashboard แล้ว ต้องตรวจผลว่าคืน 1 แถว และ `remaining_qa_rooms` เป็น 0

## ลำดับแก้ไขที่เสนอ

1. แก้การรับ broadcast ของตนเองและ component IDs ให้การจั่ว/สร้างของเกิดครั้งเดียวทุกฝั่ง

3. แก้ lifecycle ห้อง การออกห้อง การกลับไป local และการ reconnect
4. ทำให้รหัสผ่านห้องตรวจที่ฝั่งเซิร์ฟเวอร์ แล้วตรวจสิทธิ์ตาราง rooms
